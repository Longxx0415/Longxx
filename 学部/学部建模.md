# 模型概述

本文构建了一个高校部门编制配置的组合预测与预算约束调整模型。整体建模思路如下：

1.  **基于工作量指标的初始编制预测（$\mathbf{Q}^{(1)}$）**：借鉴马树才等提出的编制配置与总量调控方法，以部门工作量指标（如本科生、研究生、各类在编人员、派遣人员、科研助理等）为基础，通过主成分分析法（PCA）将多项指标合成为综合职能强度指标，进而预测各部门的编制配置数。

2.  **基于部门特征的回归编制预测（$\mathbf{Q}^{(2)}$）**：利用部门其他特征指标（如学科实力指数、是否公共教学、学科热度等），通过逐步回归（Lasso特征筛选+OLS估计）建立编制人数与部门特征之间的回归模型，得到另一组编制预测值。

3.  **组合预测**：采用方差倒数法定权，将上述两种方法的预测结果进行加权组合，充分利用工作量指标与部门特征两方面的信息，得到综合预测值
    $\mathbf{Q}^{(c)}$。

4.  **预算约束调整**：在组合预测的基础上，引入部门总编制预算约束
    $B$。若组合预测总人数超出预算，则通过惩罚函数法将约束优化问题转化为无约束问题，解析求解得到既尽可能接近原始预测值、又满足预算约束的调整后编制配置。

# 符号定义与数据矩阵

设有 $n$
个部门，需分别预测各部门的正科、副科及科级及以下编制人数（共3个层级）。定义以下数据矩阵：

  **矩阵**                      **来源**       **维度**         **含义**
  ----------------------------- -------------- ---------------- ------------------------------------------------------------------------------------
  $\mathbf{X}^{(1)}$ (Input1)   puredata.csv   $n \times m_1$   工作量指标矩阵（本科生、研究生、党员人数、在编各类人员、双轨制、派遣、科研助理等）
  $\mathbf{X}^{(2)}$ (Input2)   puredata.csv   $n \times m_2$   部门特征矩阵（学科实力指数、是否公共教学、学科热度等）
  $\mathbf{D}^{(1)}$ (Data)     data.csv       $n \times m_1$   新样本工作量指标，与 $\mathbf{X}^{(1)}$ 同结构
  $\mathbf{D}^{(2)}$ (Data2)    data.csv       $n \times m_2$   新样本部门特征，与 $\mathbf{X}^{(2)}$ 同结构
  $\mathbf{Y}$ (Output)         puredata.csv   $n \times 3$     实际编制矩阵，第1--3列分别为正科、副科、科级及以下人数 $y_{ij}$

  : 数据矩阵定义

其中 $i=1,2,\ldots,n$ 为部门序号，$j=1,2,3$
分别对应正科、副科、科级及以下。

# 基于工作量指标的初始编制预测（$\mathbf{Q}^{(1)}$）

## 数据标准化

为消除量纲影响，对训练集工作量指标矩阵 $\mathbf{X}^{(1)}$
按列进行标准化。设第 $k$ 列原始数据为 $x_{ik}^{(1)}$，则标准化后数据
$z_{ik}$ 为： $$\begin{equation}
z_{ik} = \frac{x_{ik}^{(1)} - \bar{x}_k^{(1)}}{s_k}, \qquad i=1,2,\ldots,n;\; k=1,2,\ldots,m_1
\end{equation}$$ 其中 $$\begin{equation}
\bar{x}_k^{(1)} = \frac{1}{n}\sum_{i=1}^{n} x_{ik}^{(1)}, \qquad
s_k = \sqrt{\frac{1}{n}\sum_{i=1}^{n}\left(x_{ik}^{(1)} - \bar{x}_k^{(1)}\right)^2}
\end{equation}$$ 分别为第 $k$
列的样本均值与样本标准差。记标准化后的训练集矩阵为
$\mathbf{Z} = (z_{ik})_{n \times m_1}$。

## 主成分分析与综合职能强度

对标准化矩阵 $\mathbf{Z}$
求协方差阵（或相关阵）$\mathbf{R}$，计算其特征根
$\lambda_1 \geq \lambda_2 \geq \cdots \geq \lambda_{m_1} > 0$
及对应的单位特征向量
$\mathbf{a}_k = (a_{k1}, a_{k2}, \ldots, a_{km_1})^\top$。取前 $p$
个主成分（本文取 $p=6$），使得累计方差贡献率满足： $$\begin{equation}
\sum_{k=1}^{p} \beta_k \geq 85\% \sim 95\%, \qquad \beta_k = \frac{\lambda_k}{\sum_{l=1}^{m_1} \lambda_l}
\end{equation}$$

第 $i$ 个部门在第 $k$ 个主成分上的得分为： $$\begin{equation}
F_{ik} = \sum_{l=1}^{m_1} a_{kl} z_{il} = \mathbf{a}_k^\top \mathbf{z}_i
\end{equation}$$

以方差贡献率 $\beta_k$ 为权重，将 $p$ 个主成分加权合成，得到第 $i$
个部门的综合工作量（职能强度）。由于正科、副科、科级及以下共用同一套工作量指标，故对每一层级
$j$ 均有： $$\begin{equation}
H_{ij} = \sum_{k=1}^{p} \beta_k F_{ik}, \qquad i=1,2,\ldots,n;\; j=1,2,3
\end{equation}$$

矩阵形式可写为
$\mathbf{H} = \mathbf{Z} \mathbf{A}^\top \boldsymbol{\beta}$，其中
$\mathbf{A} = (\mathbf{a}_1, \mathbf{a}_2, \ldots, \mathbf{a}_p)^\top \in \mathbb{R}^{p \times m_1}$，$\boldsymbol{\beta} = (\beta_1, \beta_2, \ldots, \beta_p)^\top$。

为区分训练集与新样本，记：

- 基于训练集 $\mathbf{X}^{(1)}$ 计算得
  $\mathbf{H} = (H_{ij})_{n \times 3}$（表示现有工作量）；

- 基于新样本 $\mathbf{D}^{(1)}$（使用同一套 $\mathbf{A}$ 与
  $\boldsymbol{\beta}$）计算得
  $\mathbf{H}' = (H'_{ij})_{n \times 3}$（表示进行预测时，基于各数据计算的下一年工作量）。

## 编制职能强度指数与初始配置

将各部门综合工作量与实际编制对比，求得每一编制承担的职能强度指数：
$$\begin{equation}
h_{ij} = \frac{H_{ij}}{y_{ij}}, \qquad \text{当 } y_{ij} > 0 \text{ 时}
\end{equation}$$

由工作量矩阵反推预测编制配置数： $$\begin{equation}
\boxed{Q^{(1)}_{ij} = \frac{H'_{ij}}{\bar{h}_j}, \qquad i=1,2,\ldots,n;\; j=1,2,3}
\end{equation}$$

同时，基于训练集 $\mathbf{X}^{(1)}$ 可得拟合值
$\hat{Q}^{(1)}_{ij} = H_{ij} / \bar{h}_j$，用于后续方差倒数定权。

# 基于部门特征的回归编制预测（$\mathbf{Q}^{(2)}$）

为引入学科实力、公共教学属性等部门特征因素，对 $\mathbf{Y}$
的每一列分别建立回归模型。

## 特征选择（Lasso逐步回归）

对第 $j$ 列（$j=1,2,3$），以 $\mathbf{X}^{(2)}$
为自变量，建立Lasso回归（已通过SPSS确定交互项不显著，故此处不再考虑）：
$$\begin{equation}
\min_{\boldsymbol{\gamma}_j, \gamma_{0j}} \left\{ \sum_{i=1}^{n} \left(y_{ij} - \gamma_{0j} - \sum_{l=1}^{m_2} \gamma_{lj} x^{(2)}_{il}\right)^2 + \alpha_j \sum_{l=1}^{m_2} |\gamma_{lj}| \right\}
\end{equation}$$

通过交叉验证选取最优惩罚参数 $\alpha_j^*$，得到稀疏系数
$\hat{\boldsymbol{\gamma}}_j$。记被选中的特征集合为
$\mathcal{S}_j = \{l : \hat{\gamma}_{lj} \neq 0\}$。若
$\mathcal{S}_j = \emptyset$，则退化为使用全部变量。

## OLS参数估计与预测

对选中特征 $\mathcal{S}_j$ 进行普通最小二乘估计，得到回归系数
$\hat{\boldsymbol{\theta}}_j$。将新样本 $\mathbf{D}^{(2)}$ 与训练集
$\mathbf{X}^{(2)}$ 分别代入回归方程，得到： $$\begin{equation}
Q^{(2)}_{ij} = \hat{\theta}_{0j} + \sum_{l \in \mathcal{S}_j} \hat{\theta}_{lj} d^{(2)}_{il}, \qquad
\hat{Q}^{(2)}_{ij} = \hat{\theta}_{0j} + \sum_{l \in \mathcal{S}_j} \hat{\theta}_{lj} x^{(2)}_{il}
\end{equation}$$

其中 $\hat{Q}^{(2)}_{ij}$ 为训练集拟合值，用于后续定权；$Q^{(2)}_{ij}$
为新样本预测值。

# 方差倒数法定权与组合预测

计算两种方法在训练集上的拟合误差方差： $$\begin{equation}
\sigma^2_j(\mathbf{Q}^{(1)}) = \frac{1}{n}\sum_{i=1}^{n} \left(\hat{Q}^{(1)}_{ij} - y_{ij}\right)^2, \qquad
\sigma^2_j(\mathbf{Q}^{(2)}) = \frac{1}{n}\sum_{i=1}^{n} \left(\hat{Q}^{(2)}_{ij} - y_{ij}\right)^2
\end{equation}$$

按方差倒数法定权，第 $j$ 层级的权重为： $$\begin{equation}
w^{(1)}_j = \frac{1/\sigma^2_j(\mathbf{Q}^{(1)})}{1/\sigma^2_j(\mathbf{Q}^{(1)}) + 1/\sigma^2_j(\mathbf{Q}^{(2)})}, \qquad
w^{(2)}_j = \frac{1/\sigma^2_j(\mathbf{Q}^{(2)})}{1/\sigma^2_j(\mathbf{Q}^{(1)}) + 1/\sigma^2_j(\mathbf{Q}^{(2)})}
\end{equation}$$ 显然
$w^{(1)}_j + w^{(2)}_j = 1$。预测误差方差越小，对应权重越大。

组合预测最终值为： $$\begin{equation}
\boxed{Q^{(c)}_{ij} = w^{(1)}_j \cdot Q^{(1)}_{ij} + w^{(2)}_j \cdot Q^{(2)}_{ij}, \qquad i=1,2,\ldots,n;\; j=1,2,3}
\end{equation}$$

# 预算约束下的编制调整

得到组合预测值 $Q^{(c)}_{ij}$ 后，对第 $i$ 个部门，记调整前的预测值为
$y_j = Q^{(c)}_{ij}$（$j=1,2,3$
分别对应正科、副科、科级及以下），调整后的配置值为
$\hat{y}_j$。设该部门总编制预算为 $B$。

## 约束优化问题

为使调整后的编制配置尽可能接近组合预测值，同时满足总预算约束，建立如下二次规划问题：
$$\begin{equation}
\begin{aligned}
\min_{\hat{y}_1,\hat{y}_2,\hat{y}_3} \quad & \sum_{j=1}^{3} (\hat{y}_j - y_j)^2 \\
\text{s.t.} \quad & \hat{y}_1 + \hat{y}_2 + \hat{y}_3 \leq B
\end{aligned}
\end{equation}$$

## 惩罚函数法与无约束转化

引入惩罚参数 $\lambda > 0$，将上述约束问题转化为无约束优化问题：
$$\begin{equation}
\min_{\hat{y}_1,\hat{y}_2,\hat{y}_3} \quad \sum_{j=1}^{3} (\hat{y}_j - y_j)^2 + \lambda \cdot \max\left\{0,\; \hat{y}_1 + \hat{y}_2 + \hat{y}_3 - B\right\}
\end{equation}$$

其中 $\max\{0, \sum_{j=1}^{3}\hat{y}_j - B\}$
为超出预算的惩罚项，$\lambda$ 为惩罚系数，$\lambda$
越大，对超预算的"容忍度"越低。

## 解析求解

根据组合预测值是否超出预算，分两种情形讨论：

**情形一：组合预测未超出预算**\
若
$\sum_{j=1}^{3} y_j \leq B$，则惩罚项不激活，最优解即为原始组合预测值：
$$\begin{equation}
\boxed{\hat{y}_j = y_j, \qquad j=1,2,3}
\end{equation}$$

**情形二：组合预测超出预算**\
若 $\sum_{j=1}^{3} y_j > B$，此时在最优解处必有
$\sum_{j=1}^{3} \hat{y}_j > B$，惩罚项激活。目标函数化为：
$$\begin{equation}
\min_{\hat{y}_1,\hat{y}_2,\hat{y}_3} \quad \sum_{j=1}^{3} (\hat{y}_j - y_j)^2 + \lambda \left(\sum_{j=1}^{3} \hat{y}_j - B\right)
\end{equation}$$

对各变量分别求偏导并令其为零： $$\begin{equation}
\frac{\partial}{\partial \hat{y}_j} = 2(\hat{y}_j - y_j) + \lambda = 0, \qquad j=1,2,3
\end{equation}$$

解得： $$\begin{equation}
\hat{y}_j = y_j - \frac{\lambda}{2}, \qquad j=1,2,3
\end{equation}$$

将上式代入预算约束等式
$\sum_{j=1}^{3} \hat{y}_j = B$（超出时最优解必位于约束边界），得：
$$\begin{equation}
\sum_{j=1}^{3} \left(y_j - \frac{\lambda}{2}\right) = B \quad\Rightarrow\quad \sum_{j=1}^{3} y_j - \frac{3\lambda}{2} = B
\end{equation}$$

解得惩罚参数： $$\begin{equation}
\lambda = \frac{2}{3}\left(\sum_{j=1}^{3} y_j - B\right)
\end{equation}$$

代回 $\hat{y}_j$ 表达式，得到最终调整后的编制配置： $$\begin{equation}
\boxed{\hat{y}_j = y_j - \frac{1}{3}\left(\sum_{l=1}^{3} y_l - B\right), \qquad j=1,2,3}
\end{equation}$$
